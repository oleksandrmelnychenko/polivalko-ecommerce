# Poli Valko — стан і план від А до Б

Стан на 28.10.2026. **А** — що вже працює. **Б** — перший публічний запуск за ТЗ.
Там, де немає доступів замовника, стоять заглушки з тим самим контрактом, що й справжні інтеграції
(див. [integrations.md](integrations.md)): заміна заглушки не змінює ні API, ні вітрину, ні консоль.

Перевірено 28.10.2026:

- 102 тести бекенду, з них 50 інтеграційних: прямі HTTP-запити без Next.js.
  - Оплата, підробка й дублікати вебхуків, повернення, чеки, кур'єр.
  - Каталог у консолі, імпорт CSV, тексти, працівники, ручний повтор операцій.
- Наскрізний сценарій у headless Chrome на Docker-стеку (:8080):
  - варіанти й фільтр за характеристиками;
  - оформлення, відмова банку, повторна оплата, успіх;
  - відправлення, повернення в банк, чеки продажу й повернення, картка товару, інтеграції.
- `sloplint` Hallmark: 0 FAIL на нових сторінках вітрини й консолі.

## Як подивитися

```bash
docker compose --profile app up -d --build
```

Відкрийте http://localhost:8080.

- **Покупка:** товар → «Купити» → «Оформити» → «Онлайн карткою» → «Оплатити». На тестовій сторінці оплати можна обрати відмову, прострочення, успіх або «втрачений вебхук».
- **Консоль:** http://console.localhost:8080/login.
- **Тестові облікові записи:** локально — у `src/PoliValko.Api/appsettings.Development.json` (`Seed:Users`); у Docker — перший адміністратор з `ADMIN_EMAIL` і `ADMIN_PASSWORD`.

## Що потрібно від замовника

- **Доступи:** Navkolo (API і документація), платіжний провайдер, Checkbox, ключ Нової пошти, GA4 і Search Console.
- **Продавець:** реквізити (назва, ЄДРПОУ/РНОКПП, адреса), рішення бухгалтера щодо чеків для післяплати й самовивозу.
- **Бренд:** логотип і фото товарів. Найбільше покращить сторінку фото для пропозиції на першому екрані головної (квадрат або 3:4, від 1200 px).
- **Контакти:** адреса, графік і телефони магазину в Бучі, описи семи напрямків послуг.
- **Погодження:**
  - контраст кнопок: брендовий #00A046 для акцентів, #00873B для кнопок і зеленого тексту (WCAG AA);
  - правила видимості групи «Хлам»;
  - кількість одночасних відвідувачів для навантажувального тесту.
